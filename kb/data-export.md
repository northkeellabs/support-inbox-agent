# Exporting your data

> Fictional help article for Ledgerline (Demo), a made-up invoicing app used in a demo.

## What you can export

You can export invoices, customers, payments, tax rates and line items. The export is available on every plan, including Free. Files contain your data only, never the data of other accounts.

## How to export

Follow these steps:

1. Go to Settings > Data > Export.
2. Choose what to include and a date range, or select All data.
3. Pick CSV or JSON as the format.
4. Select Request export.

Ledgerline emails a download link when the file is ready.

## How long it takes

Small accounts are usually ready in a few minutes. Large accounts can take up to 24 hours. The link is valid for 7 days, and you can request a new export after that. Only one export can run at a time per account.

## Format details

CSV exports use UTF-8 encoding with a comma separator and one file per data type, packaged in a ZIP. JSON exports contain one file with all records and nested line items. Dates are written in the date format set in Settings > Business > Regional settings, so check that setting if the dates look wrong.

## Who can export and security

Owners and Admins can request exports. The download link is sent only to the email of the person who requested it and requires a signed-in session. If you need a full copy of your personal data for privacy reasons, see the GDPR data requests article.
