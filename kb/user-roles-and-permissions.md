# User roles and permissions

> Fictional help article for Ledgerline (Demo), a made-up invoicing app used in a demo.

## Available roles

Ledgerline has four roles: Owner, Admin, Member and Billing. There is exactly one Owner per account. The number of users depends on your plan: Free 1, Starter 3, Growth 10, and Scale unlimited.

## What each role can do

The roles work as follows:

- Owner: everything, including closing the account and changing the owner.
- Admin: manage users, settings, API keys and SSO, but not close the account.
- Member: create and edit invoices, customers and payments.
- Billing: view and change the plan, payment card and receipts, and view invoices read-only.

## Invite a user

Go to Settings > Users > Invite user, enter the email address and choose a role. The invitation is valid for 7 days and can be resent or cancelled from the same page. A user who is invited but has not accepted still counts toward your plan limit.

## Change or remove a user

Select the user in Settings > Users and choose Change role or Remove. Removing a user signs them out within a few minutes but keeps the invoices and records they created. You cannot remove the Owner; transferring ownership requires identity verification through the security team.

## Audit trail

Scale accounts can see who changed what under Settings > Security > Audit log, kept for 12 months. On other plans the invoice history shows changes to a single invoice with the user name and time, but there is no account-wide log.
